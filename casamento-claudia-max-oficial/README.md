# Convite de casamento — Cláudia & Max

Site estático com animação de transição entre envelope fechado, envelope aberto e convite.

## Render
- Root Directory: `convite-casamento-cinematico`
- Build Command: em branco
- Publish Directory: `.`

Envie o conteúdo da pasta `convite-casamento-cinematico` para a pasta de mesmo nome no repositório. As imagens para celular e computador já estão em `assets`.

Nota: a animação faz uma transição entre fotografias e anima o selo; a abertura física de fita e abas exigiria imagens recortadas em camadas independentes. A posição do selo pode ser ajustada em `.seal` no CSS para corresponder à fotografia.
